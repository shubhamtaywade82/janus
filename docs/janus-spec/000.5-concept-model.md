## 1. Core Philosophy: The Uncertainty Reduction Cascade
In the Janus Epistemological Meta-Model (`janus-meta`), the runtime operates as a continuous state-reduction pipeline. Uncertainty in market data is mathematically transformed into confirmed knowledge.

The **Concept Model** defines the five distinct lifecycle stages that classify every node in the runtime knowledge graph:

```
    [MetaObservation] (Exchange Raw Ticks)
           │
           ▼
     [MetaInference]  (Probabilistic Calculations / Hypotheses)
           │
           ▼
     [MetaKnowledge]  (Corroborated, Structural Topology Facts)
           │
           ▼
      [MetaDecision]  (Validated policy actions & executions)
           │
           ▼
    [MetaProjection]  (Optimized, derived state views)
```

---

## 2. The Five Epistemological Stages

### 2.1 MetaObservation (Level 0 Primitives)
- **Definition**: Raw, immutable, sensory events from external sources.
- **State Rule**: A MetaObservation has no state machine. It is created in a terminal state of `OBSERVED`.
- **Certainty**: Deterministic (1.0).

### 2.2 MetaInference (Level 1-2 Derived Facts)
- **Definition**: Stateful, probabilistic deductions computed from observations.
- **State Machine**:
  - `FORMING`: Cumulative parameters are building (e.g. FVG mid-candle).
  - `ACTIVE`: Parameters are finalized; the inference is a valid active hypothesis.
  - `RESOLVED`: The inference has terminated (e.g. FVG fully filled / mitigated).
- **Certainty**: Stochastic (0.0 to 1.0) represented by dynamic confidence coefficients.

### 2.3 MetaKnowledge (Level 3-4 Causal Facts)
- **Definition**: Inferences that have accumulated sufficient historical and spatiotemporal evidence to be accepted as structural market truth.
- **State Machine**:
  - `UNCONFIRMED`: A pattern is detected but lacks secondary evidence.
  - `CONFIRMED`: Corroborated by independent evidence sources.
  - `WEAKENED`: Lacks recent reinforcing observations, subject to exponential confidence decay.
  - `INVALIDATED`: Contradicted by new contradictory observations.

### 2.4 MetaDecision (Level 5-6 Action)
- **Definition**: The commitment to trigger a system action or modify the execution state.
- **State Machine**:
  - `PROPOSED`: Evaluated by a strategy system and passed to risk policies.
  - `APPROVED`: Passed all temporal, risk, and drawdown invariants.
  - `REJECTED`: Vetoed by a safety invariant.
  - `EXECUTED`: Dispatched to the exchange adapter.

### 2.5 MetaProjection (Derived Views)
- **Definition**: An optimized, read-only cache view derived from active graph layers.
- **State Rule**: Eventually consistent with the active graph. Has no state transitions.
