# JDS-003.1: MarketObject Class Taxonomy
Version: 1.0
Status: Approved

All structures in the Janus Market Ontology inherit from the base `MarketObject` class. This document defines the subclass fields and taxonomical structure.

```
                    +-----------------------------+
                    |   MarketObject (Abstract)   |
                    +-----------------------------+
                                   |
         +-------------------------+-------------------------+
         |                         |                         |
  +--------------+          +--------------+          +--------------+
  | FairValueGap |          |  OrderBlock  |          | LiquidityPool|
  +--------------+          +--------------+          +--------------+
         |                         |                         |
    (BISI/SIBI)            (Bullish/Bearish)           (Buyside/Sellside)
```

---

## 1. Abstract Base Class
```typescript
abstract class MarketObject {
  readonly id: string;                  // Unique UUID v4
  readonly symbol: string;              // e.g. BTC-USDT
  readonly timeframe: string;           // e.g. 15m
  readonly creationTimestamp: number;   // Unix epoch (ms)
  readonly startPrice: number;          // Lower boundary
  readonly endPrice: number;            // Upper boundary
  readonly candleIndexStart: number;    // Absolute index in kline table
  candleIndexEnd?: number;              // Set once object is invalidated/consumed
  isInvalidated: boolean = false;
  invalidatedAtTimestamp?: number;
}
```

---

## 2. Concrete Subclasses

### 2.1 FairValueGap (FVG)
Models a three-candle sequence where price moves rapidly, leaving an imbalance that has not been overlapping.
- **Taxonomy Fields**:
  - `imbalanceType`: `'BISI'` (Buyside Imbalance Sellside Inefficiency - bullish gap) or `'SIBI'` (Sellside Imbalance Buyside Inefficiency - bearish gap).
  - `mitigationPct`: `number` (rolling percentage of the gap filled by price wicks, 0.0 to 100.0).
  - `volumeProfile`: `VolumeProfileNode` inside the gap zone.

### 2.2 OrderBlock (OB)
Models institutional placement zones. Bullish OB is the last down candle before a sharp move up; Bearish OB is the last up candle before a sharp move down.
- **Taxonomy Fields**:
  - `direction`: `'BULLISH'` | `'BEARISH'`.
  - `isMitigated`: `boolean`.
  - `meanPrice`: `number` (the equilibrium price / 50% level of the OB candle).
  - `volumePoc`: `number` (Point of Control volume price within the block).

### 2.3 LiquidityPool
Represents clusters of stop-loss or limit orders resting above or below swing pivots.
- **Taxonomy Fields**:
  - `poolType`: `'BUY_SIDE'` (resistance peaks) | `'SELL_SIDE'` (support troughs).
  - `volumeEstimate`: `number` (projected liquidity resting in the pool).
  - `sweepCount`: `number` (number of times wicks have pierced this zone without a body close).

### 2.4 Swing
Represents local extrema pivots.
- **Taxonomy Fields**:
  - `swingType`: `'HIGH'` | `'LOW'`.
  - `strength`: `number` (number of surrounding candles checked, e.g. 5, 9, 13).
  - `isSwept`: `boolean`.

### 2.5 MarketStructureShift (MSS)
Represents a structural shift.
- **Taxonomy Fields**:
  - `triggerPrice`: `number` (the price level of the swing high/low that was breached).
  - `displacementVolume`: `number` (volume delta measured during the breach candle).\n
