# JDS-003.2: Object Meta-Model Specification
Version: 1.0
Status: Approved

Every `MarketObject` node in the Janus platform holds metadata describing its origin, geometry, confidence, and context. This document details the Meta-Model structure.

```typescript
interface ObjectMetaModel {
  spatialNature: SpatialProperties;
  temporalNature: TemporalProperties;
  kind: ObjectKind;
  geometry: ObjectGeometry;
  confidence: ConfidenceMetrics;
  sources: DataSources;
  dependencies: string[]; // List of MarketObject IDs
}
```

---

## 1. Spatial Properties
Declares where the object resides in price coordinates.
- **Properties**:
  - `startPrice`: Floor limit of the object.
  - `endPrice`: Ceiling limit of the object.
  - `averagePrice`: Midpoint or volume Point of Control.
  - `priceBreadth`: Width of the level in absolute currency and percentage.

## 2. Temporal Properties
Determines how the object evolves over time.
- **Properties**:
  - `creationTimestamp`: Unix epoch of the candle close that formed the object.
  - `halfLifeSeconds`: Rate of temporal decay (relevance decreases as time passes).
  - `maxRelevanceCandles`: Maximum number of candles before the level is automatically pruned.

## 3. Object Kind & Geometry
Defines the dimensional nature of the structure.
- **ObjectKind**: `'STRUCTURAL_LEVEL'` | `'IMBALANCE_ZONE'` | `'LIQUIDITY_CLUSTER'` | `'TRANSITIONAL_STATE'`.
- **ObjectGeometry**:
  - `Point`: Fixed coordinate (e.g. Swing Peak price).
  - `Zone`: Two-dimensional Price-Time box (e.g. Fair Value Gap, OrderBlock).
  - `Vector`: A moving trend-line or regression channel.

## 4. Confidence Metrics
A statistical grading score assigned during detection.
- **Properties**:
  - `detectionConfidence`: Confidence score (0.0 to 1.0) based on signal strength.
  - `validationConfirmations`: Number of times indicators on other timeframes confirm the level.
  - `volumeImbalanceRatio`: The volume ratio backing the level formation.

## 5. Data Sources & Dependencies
Tracks lineage and parent nodes.
- **DataSources**: `symbol`, `feedName` (Binance/CoinDCX), `timeframe`.
- **Dependencies**: List of UUIDs of other `MarketObjects` that are required to validate this object (e.g., a `BreakerBlock` depends on the parent `OrderBlock` that was violated).\n
