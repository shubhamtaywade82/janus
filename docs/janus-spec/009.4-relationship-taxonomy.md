## 1. Core Philosophy: The Semantic Families
Edges in the Janus Temporal Knowledge Graph are partitioned into **Semantic Families**. This taxonomy ensures that different systems (realtime, batch, statistical, execution, and AI) only manipulate and query relationships relevant to their concerns, preventing logical drift and ensuring high-performance graph traversals.

---

## 2. Relationship Families

### 2.1 Structural Relationships (Spatial Geometry)
Map physical boundaries and nesting of structures across timeframes:
- **`CONTAINS`**: Node A (e.g. H4 FVG) geographically encompasses Node B (e.g. M15 FVG).
- **`OVERLAPS`**: Node A shares a portion of its price range with Node B.
- **`ALIGNS_WITH`**: Node A and Node B align at the exact same horizontal level (e.g., equal highs).

### 2.2 Temporal Relationships (Time Sequencing)
Map the chronological order of occurrence:
- **`PRECEDES`**: Node A's creation is strictly prior to Node B.
- **`FOLLOWS`**: Node A's creation occurs after Node B.
- **`SIMULTANEOUS`**: Node A and Node B formed within the same candle window.

### 2.3 Causal Relationships (Event Dynamics)
Represent state changes triggered by market interactions:
- **`TRIGGERS`**: Node A causes the validation of Node B (e.g. `BOS` triggers `OrderBlock` validation).
- **`INVALIDATES`**: Price action through Node A invalidates Node B.
- **`SWEEPS`**: Price action wicks through a `LiquidityPool` and returns.
- **`FILLS`**: Price action penetrates and mitigates an imbalance zone.

### 2.4 Trading Relationships (Execution Mapping)
Map system execution entities to market structures:
- **`ENTRY_FOR`**: A `TradeWorkflow` uses this object to route entry orders.
- **`TARGET_FOR`**: A `TradeWorkflow` uses this object to target exits (take profit).
- **`STOP_FOR`**: A `TradeWorkflow` uses this object to anchor its stop-loss.
- **`CONTEXT_FOR`**: A higher-timeframe object acts as the bias filter for a lower-timeframe workflow.

### 2.5 Statistical Relationships (Quantitative Vectors)
Map statistical correlation and relative distributions:
- **`CORRELATES`**: High Pearson Correlation between two dynamic curves (e.g., BTC and ETH).
- **`DIVERGES`**: Momentum or CVD diverges from price action.
- **`COINTEGRATES`**: Two assets share a stationary statistical spread.

### 2.6 AI Relationships (Semantic Narrative)
Used exclusively by the AI Brain for semantic narrative profiling. *These edges are invisible to the hot-path Strategy Engine.*
- **`SUPPORTS_NARRATIVE`**: An edge supports the current narrative (e.g. "Liquidity grab supports a Bull Trap thesis").
- **`CONTRADICTS`**: An edge opposes the narrative.
- **`EXPLAINS`**: Explains a sudden market shock.
