## 1. Core Philosophy: Knowledge-Centric Computation
The **Janus Meta-Model** (`janus-meta`) is a continuous temporal computation engine, not a business information system. Traditional modeling frameworks (e.g. MOF, EMF) are built around static objects, properties, and persistence models.

Janus, instead, is built around **uncertainty reduction and knowledge representation**. Everything in the M3 layer is centered on how raw market data transitions from observation to confirmed knowledge, and finally into deterministic decisions.

---

## 2. The Semantic Primitive Stack (M3)

The M3 Meta layer replaces "Objects" and "Properties" with seven domain-agnostic computational primitives:

```
┌────────────────────────────────────────────────────────┐
│ 1. MetaObservation                                     │ (Raw, immutable primitive ticks/inputs)
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼ (Drives)
┌────────────────────────────────────────────────────────┐
│ 2. MetaInference                                       │ (Stateful calculations over observations)
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼ (Verifies)
┌────────────────────────────────────────────────────────┐
│ 3. MetaKnowledge                                       │ (Confirmed structural/causal topologies)
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼ (Decides)
┌────────────────────────────────────────────────────────┐
│ 4. MetaDecision                                        │ (Policy state validation & intent)
└────────────────────────────────────────────────────────┘
```

### 2.1 MetaConcept
- **Definition**: The base node class for all structural schemas.
- **Role**: All observations, inferences, knowledge, and decisions inherit from `MetaConcept`.

### 2.2 MetaObservation (M0 Layer 1)
- **Definition**: Raw, immutable, atomic data points directly ingested from exchange feeds (e.g. Price ticks, order book ticks).

### 2.3 MetaInference (M0 Layer 2)
- **Definition**: Derived spatiotemporal facts calculated from observations (e.g. a calculated imbalance zone or volatility surge).

### 2.4 MetaKnowledge (M0 Layer 3)
- **Definition**: Stable, confirmed patterns representing physical structure or causal relationships in the market (e.g. a Liquidity Sweep or trend continuation).

### 2.5 MetaDecision (M0 Layer 4)
- **Definition**: The terminal output of evaluating policies and rules, generating execution intents (e.g. entering a position).

### 2.6 MetaConstraint
Decoupled into five specialized categories:
- **Axioms**: Mathematical physics laws that are universally true (e.g., `High >= Low`).
- **Invariants**: Domain rules that must never be violated (e.g., `Closed positions cannot receive fills`).
- **Policies**: Configurable system parameters (e.g., `Max Drawdown = 5%`).
- **Rules**: If-Then tactical instructions (e.g., `If RSI > 70 then ...`).
- **Optimizations**: Graph pruning/folding heuristics (e.g., `Merge duplicate FVGs`).

### 2.7 MetaProjection
- **Definition**: Pure stateless systems that compute mapping transformations between layers (e.g. converting an Observation Graph stream into an Inference Graph).

## 3. First-Class Semantic Dimensions (No Raw Properties)
Instead of using a generic `Property` bucket, concepts define themselves using strict semantic dimensions:

- **Identity**: Globally unique, time-sortable references.
- **Geometry**: Spatial footprints (Point, Range, Zone coordinates).
- **Temporal**: Time vectors, orderings, and durations.
- **Probability**: Confidence metrics and distributions.
- **Lineage**: Provenance and evidence tracing back to Level 0 observations.
- **Lifecycle**: Statechart state graphs.
