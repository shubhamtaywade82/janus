 # Plan: Unified Paper-Live Mode for Janus

## Goal
Simplify Janus to a single `PLACE_ORDERS` toggle for CoinDCX:
- **`PLACE_ORDERS=false`**: Never sends real orders. Auto-executor creates only paper positions. CoinDCX WS, REST sync, position reconciliation, wallet fetch, and liquidation monitor stay fully active so the dashboard always shows real CoinDCX live positions + local paper positions.
- **`PLACE_ORDERS=true`**: Auto-executor sends real orders to CoinDCX and tracks them as live positions.
- **Chart + Dashboard**: Both paper and live positions/orders render simultaneously with distinct visual modes (dashed vs solid entry lines, mode badges).

---

## Constraints
- No new npm dependencies.
- Preserve `PAPER_TRADING`/`TRADING_MODE` env vars for backward compat but `PLACE_ORDERS` becomes the primary execution gate.
- No database schema changes (`positions.is_paper` already exists).
- CoinDCX private WS always connects when credentials exist.
- Market data remains Binance primary + CoinDCX fallback.

1. **API** — In `api/routers/trading-router.ts`, add a new `paperOrders` query:
   ```ts
   paperOrders: authedQuery
     .input(z.object({ symbol: z.string().optional() }))
     .query(async ({ input, ctx }) => {
       const db = getDb();
       const conditions = [
         eq(positions.userId, ctx.user.id),
         eq(positions.status, "open"),
         eq(positions.isPaper, true),
       ];
       if (input.symbol) conditions.push(eq(positions.symbol, input.symbol));
       const rows = await db.select().from(positions).where(and(...conditions));
       return rows.map((p) => ({
         id: String(p.id),
         symbol: p.symbol,
         coindcxPair: `B-${p.symbol.replace("USDT", "_USDT")}`,
         side: p.side === "long" ? "buy" : "sell",
         orderType: "market_order",
         price: parseFloat(p.entryPrice),
         quantity: parseFloat(p.size),
         filledQuantity: parseFloat(p.size),
         status: "filled",
         createdAt: p.createdAt,
         isPaper: true,
       }));
     });
   ```

## Decision Log
| Decision | Rationale | Rejected Alternative |
|---|---|---|
| `isPaperMode = !env.placeOrders` | Single toggle is exactly what the user asked for | Keeping `TRADING_MODE` enum as primary |
| Chart paper = dashed, live = solid | Dashed implies "not real" intuitively | Using colors only (color-blind issue) |
| Paper orders derived from open positions | Paper mode has no real pending orders; synthetic orders let us show them in the same panel | Separate "Paper Orders" panel (too much UI clutter) |

## Risks
| Risk | Likelihood | Mitigation |
|---|---|---|
| Hardcoded `isPaperMode = true` was intentional for safety | Low | Git history check; if so, add explicit env override comment |
| Always-on CoinDCX sync hits rate limits | Low | Already runs today with no changes to request frequency |
| Dashed entry lines on chart may be hard to see | Medium | Use 0.6 opacity + keep SL/TP labels |
